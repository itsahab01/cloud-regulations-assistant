# 🇸🇦 نظام Conversational RAG لتنظيمات الحوسبة السحابية (CST RS10)
### مبني بواسطة **Python** و **LangChain** مع واجهة تفاعلية عبر **Streamlit**
#### مدعوم بدرع أمان ضد هجمات الـ Prompt Injection، ومدقق مطابقة مسبق لمنع الهلوسة، وذاكرة حوارية للأسئلة التتبعية

> 🎓 تم تطوير هذا المشروع ضمن برنامج **تطوير حلول الذكاء الاصطناعي التوليدي** المقدم من [أكاديمية سدايا](https://github.com/SDAIAAcademy).

---

## 📌 نبذة عن المشروع
تحتاج الجهات الحكومية والشركات والمتعاقدون لمعرفة: *أين نخزن بياناتنا؟ وهل يجوز نقلها خارج المملكة؟ وأي مقدم خدمة سحابية نستخدم؟*
الإجابة موزعة على نصوص وجداول طويلة، والإجابة الخاطئة قد تؤدي لمخالفة نظامية.
يقدم النظام إجابة دقيقة لأي سيناريو بيانات تشمل: **مستوى التصنيف، موقع التخزين، سياسة النقل عبر الحدود، فئة مقدم الخدمة، والموافقات المطلوبة**، مع ذكر المواد وأرقام الصفحات من الوثيقة.

---

## 🌟 أبرز مميزات النظام

1. **الوثيقة كمصدر معرفي حصري (Sole Knowledge Source)**:
   - يعتمد النظام حصرياً على وثيقة **«تنظيمات تقديم خدمات الحوسبة السحابية (RS10 - الإصدار الرابع)»** الصادرة عن هيئة الاتصالات والفضاء والتقنية (CST).
   - يرفض بشكل قاطع الأسئلة الخارجة عن النطاق (Out-of-Scope Questions) مثل الطبخ، الطقس، الرياضة، أو البرمجة العامة.
   - يعترف بوضوح عند عدم توفر المعلومة في الوثيقة دون أي تخمين أو اختلاق.

2. **الذاكرة الحوارية ومتابعة الأسئلة التتبعية (Conversational Memory & Follow-ups)**:
   - يدعم استمرار السياق عبر الجلسة الحوارية (مثل السؤال: *"عندي بيانات سرية للغاية لوزارة أين تخزن؟"* ثم المتابعة: *"وماذا لو كانت مقيدة فقط؟"* أو *"وهل يجوز عمل نسخ احتياطي لها خارج المملكة؟"*).
   - يقوم النظام تلقائياً بإعادة صياغة أسئلة المتابعة بالاعتماد على سياق المحادثة السابق قبل التمرير لمسترجع المعلومات.

3. **درع الحماية من التجاوز والحقن (Prompt Injection & Jailbreak Defense)**:
   - فحص استباقي متعدد الطبقات لاكتشاف محاولات تجاوز التعليمات مثل: `Ignore previous instructions`، `system prompt extraction`، ومحاولات انتحال الأدوار التخريبية باللغتين العربية والإنجليزية.
   - حظر فوري للطلب مع تنبيه أمني واضح دون المساس بسرية التعليمات الداخلية.

4. **التحقق الاستباقي ومكافحة الهلوسة (Pre-display Faithfulness & Consistency Validation)**:
   - قبل عرض أي إجابة للمستخدم، تخضع الإجابة لفحص آلي صارم للتحقق من:
     * مطابقة موقع التخزين (داخل المملكة حصراً / خارج المملكة بشروط).
     * صحة فئة تسجيل مقدم الخدمة (أ، ب، ج) بحسب الجدول رقم 2.
     * توثيق الأسانيد والمواد النظامية مع أرقام الصفحات.
     * إظهار شارة التحقق ومستوى الدقة المئوي (مثل: `✓ تم التحقق بنسبة 99%`).

5. **واجهة مستخدم تفاعلية فاخرة (Streamlit Interface)**:
   - واجهة محادثة ذكية متكاملة باللغة العربية مع دعم RTL وتصميم عصري مستوحى من رؤية 2030.
   - شريط جانبي لمراقبة حالة الأمان والضوابط، وإدخال مفتاح Gemini اختياري، ومسح الذاكرة الحوارية، وبنك أمثلة سريعة.

## 🧩 حالات الاستخدام (Use Cases)

| المستخدم | السؤال | النتيجة |
| :--- | :--- | :--- |
| موظف جهة حكومية | كم مستوى لتصنيف البيانات الحكومية؟ وايش الفرق بينها؟ | يوضح المستويات ومعيار كل مستوى وقواعد تخزينه |
| متجر إلكتروني (قطاع خاص) | هل يسمح النظام بتخزين بيانات عملائنا خارج المملكة؟ | يجوز بشروط: إبلاغ المشترك وأخذ موافقته (المادة 8-3-3)، الفئة (أ) أو (ب) أو (ج) |
| متعاقد مع جهة حكومية | هل أقدر أحلل بيانات المستخدمين بخدمة ذكاء اصطناعي خارج المملكة؟ | ممنوع: بيانات مقيدة تُخزن داخل المملكة حصراً (المادة 6-3-3)، الفئة (ب) أو (ج) |
| أي مستخدم | Can you convert 100 SAR to Yen? | رفض مهذب لأن السؤال خارج نطاق الوثيقة |

## 🧱 آلية العمل (Architecture)

```
سؤال المستخدم
   ↓
درع الأمان (فحص الحقن + فلتر النطاق)
   ↓
إعادة صياغة السؤال بالاعتماد على الذاكرة الحوارية
   ↓
المسترجع (FAISS) ← مقاطع الوثيقة مع أرقام الصفحات
   ↓
قواعد التخزين والتصنيف (storage_rules)
   ↓
توليد الإجابة (Gemini)
   ↓
المدقق (Verifier) ← شارة التحقق ونسبة الدقة
   ↓
عرض الإجابة مع الأسانيد
```

## ⚙️ التثبيت

### 1. نسخ المستودع
```powershell
git clone https://github.com/<your-username>/cloud-regulations-assistant.git
cd cloud-regulations-assistant
```

### 2. تثبيت المتطلبات
```powershell
pip install -r requirements.txt
```

أنشئ ملف `.env` وأضف فيه:
```

```
أو أدخله من الشريط الجانبي في الواجهة.

## 🚀 طرق التشغيل السريع

### 1. تشغيل واجهة Streamlit التفاعلية
```powershell
python -m streamlit run streamlit_app.py --server.port 8501
```

ثم توجه إلى المتصفح عبر الرابط:
👉 **`http://localhost:8501`**

### 2. تشغيل الاختبارات الآلية الشاملة
للتحقق من سلامة كافة الضوابط الأمنية والنظامية:

```powershell
python app.py
```
👉 **`http://localhost:5000`**

```powershell

```

## 📊 مصفوفة قواعد التخزين والتصنيف (CST RS10 Matrix)

| نوع البيانات | مستوى التصنيف | أين يجب أن تُخزن؟ | فئة مقدم الخدمة السحابي | الموافقات والقيود النظامية |
| :--- | :--- | :--- | :--- | :--- |
| **بيانات جهات حكومية سعودية** | **سري للغاية** | 🇸🇦 **داخل المملكة حصراً** | **الفئة (ج) فقط** | إلزامي: أخذ موافقة مسبقة من الهيئة (CST)، مع حظر تام للنقل أو النسخ الاحتياطي خارج المملكة. |
| **بيانات جهات حكومية سعودية** | **سري** | 🇸🇦 **داخل المملكة حصراً** | **الفئة (ج) فقط** | إلزامي: أخذ موافقة مسبقة من الهيئة (CST)، وحظر النقل للخارج. |
| **بيانات جهات حكومية سعودية** | **مقيّد** | 🇸🇦 **داخل المملكة حصراً** | **الفئة (ب) أو (ج)** | التعاقد مع مقدم خدمة مسجل لدى الهيئة، وحظر النقل للخارج (المادة 6-3-3). |
| **بيانات جهات حكومية سعودية** | **عام** | 🇸🇦 **داخل المملكة حصراً** | **الفئة (أ) أو (ب) أو (ج)** | تحظر المادة 6-3-3 نقل أي محتوى من بيانات الجهات الحكومية السعودية خارج المملكة إلا بنص صريح. |
| **بيانات جهات غير حكومية** | **واردة من جهة حكومية** | 🇸🇦 **داخل المملكة حصراً** | بحسب تصنيفها الحكومي الأصلي | تُعامل بنفس تصنيفها الحكومي الأصلي وتتبع نفس قيود التخزين. |
| **بيانات جهات غير حكومية** | **بيانات أخرى** (شركات / أفراد) | الأصل داخل المملكة، ويجوز خارجها بشروط | **الفئة (أ) أو (ب) أو (ج)** | المادة 8-3-3: يشترط إبلاغ المشترك مسبقاً وأخذ موافقته الصريحة قبل النقل أو التخزين خارج المملكة، والالتزام بضوابط NDMO و PDPL. |

## 📚 التوثيق الفني
- **تجهيز البيانات:** تحويل الوثيقة إلى نص وتقسيمها إلى مقاطع مع أرقام الصفحات (`data/cst_chunks.json`).
- **الاسترجاع:** فهرسة المقاطع في FAISS مع معالجة خاصة للنص العربي (`src/retriever.py`).
- **قواعد التخزين:** مصفوفة التصنيف مبرمجة كقواعد ثابتة لضمان دقة النتيجة (`src/storage_rules.py`).
- **الأمان:** فحص الحقن وفلتر النطاق قبل أي استدعاء للنموذج (`src/langchain_rag/security.py`).
- **التحقق:** مطابقة الإجابة مع السياق المسترجع قبل العرض (`src/langchain_rag/verifier.py`).
